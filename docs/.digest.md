# PROJECT DIGEST — OpenGraph MCP

## STACK

Monorepo TypeScript sobre **Bun 1.3.14**. Pacotes: `graph-core`, `mcp-server`, `client`, `stdio-proxy`, `claude-plugin` e `mcp-web`. Persistência: `bun:sqlite` + espelho JSONL append-only por tenant.

## ARCHITECTURE

- Pattern: **protocol core (EAP) + reference host + client adapters**.
- Layers: domínio puro → serviços duráveis → adapters MCP → HTTP/SSE → clientes/plugin/UI.
- DI: `eapServices(state, tenantId)` compõe repositories e serviços por chamada e por tenant.
- REQUIRED: Mantenha decisões de admissão determinísticas e cegas ao chamador.
- REQUIRED: Execute read-decide-write em `serialTransaction`; use `allocateSequence`.
- REQUIRED: Passe o repo em `graph.bootstrap`; não use `GRAPH_REPO_PATH`.
- PROHIBITED: Reimplemente regra de domínio em adapter MCP.
- PROHIBITED: Trate JSONL como snapshot completo do estado.

## TESTS

- Frameworks: **Bun Test** e **Playwright**.
- Commands: `bun run verify`; `bun run --cwd packages/mcp-web test:parity`.
- Gates: `bun scripts/verification/quarantine-gate.ts`; `bun scripts/verification/coverage-gate.ts`.
- Coverage EAP registrada: 91.93% linhas e 91.02% funções; ratchet bloqueante por contagens/razões.
