# PROJECT DIGEST — OpenGraph MCP

## STACK

TypeScript monorepo on **Bun**. Packages: `graph-core` (pure domain), `mcp-server` (reference host), `client`, `stdio-proxy`, `claude-plugin`, `mcp-web`. Persistence: `bun:sqlite` plus a per-tenant append-only JSONL mirror.

## ARCHITECTURE

- Pattern: **protocol core (EAP) + reference host**. Semantics live in the protocol; MCP is transport only.
- Layers: pure domain (`packages/graph-core/src/`) → durable services (`packages/mcp-server/src/eap/`) → MCP adapters (`packages/mcp-server/src/tools/`) → transport registry (`packages/mcp-server/src/transport.ts`).
- REQUIRED: Admission decisions are deterministic and blind to the caller; semantic judgement may be probabilistic, authority transitions may not.
- REQUIRED: Refusals use the closed code vocabulary with a client obligation per code.
- REQUIRED: Read-decide-write over EAP tables runs inside `serialTransaction`; sequences come from `allocateSequence`.
- PROHIBITED: Reimplementing a domain rule inside an MCP adapter.
- PROHIBITED: Treating the JSONL mirror as a complete state snapshot — `eap_sequences` and `capability_executions` are SQLite-only.

## TESTS

- Framework: **bun test**.
- Commands: `cd packages/mcp-server && bun test --timeout 30000`; same for `packages/graph-core` and `packages/client`.
- Typecheck: `bunx tsc -p packages/mcp-server/tsconfig.check.json` (the package `tsconfig.json` is broken upstream).
- Coverage: no tooling configured; no threshold exists.

## STATUS

The EAP governance services exist in the repository but are **not** wired into the transport. Only the five `cognitive.*` tools are reachable at runtime. See the feature document before assuming governance is active.
